# 📊 台股全自動選股助理

一個**自己用、24 小時運作**的台股選股工具,每天盤後自動幫你掃過全市場 ~ 1800 檔股票,
挑出符合「**法人在買 + 大戶在吃貨 + 技術面剛起漲 + 營收有成長**」的潛力股,
透過網頁看分析、透過 Telegram 每天收推播。

**最棒的是:全套免費**。雲端主機 / 資料源 / AI 點評都不用付一毛錢。

## 🎯 這套工具能幫你什麼

### 早上開盤前
打開網頁就能看到:
- 📋 **昨晚自動跑出來的達標股清單**(通常 5~20 檔)
- 🌡️ **市場溫度計**(0~100 分)告訴你今天該積極還是觀望
- 📈 **大盤多空狀態**、外資/散戶誰在做多
- 🤖 **AI 操作建議**(150 字短評)

搜尋框打**代號或名稱** → 立刻跳出:
- K 線圖(含買賣訊號標記)
- 🚦 **進場節奏燈號**(🟢 可進場 / 🟡 拉回再進 / 🔵 觀察)— **過熱會亮黃燈並說明原因**(KD 過熱、5 日漲太多、離均線太遠),避免追高

- AI 對這檔的看法
- 倉位計算機(你能虧多少 → 反推該買幾張)

### 每天 17:00 左右
打開 Telegram → **自動推送今日選股**,訊息含:
- 達標個股 Top 15
- 主流產業(看資金往哪流)
- 昨天有今天沒了的股(可能該停損)

- 近 30 日策略績效摘要;**策略明顯轉差時主動跳「系統失效警報」**(只在變差才推)

| 分頁 | 在幹嘛 |
|---|---|

## 🌡️ 大盤情緒指標(這套工具的特色之一)

把 **6 個訊號** 揉成一個 0~100 的「市場溫度」:

| 指標 | 在說什麼 |
|---|---|
| 🇺🇸 **美股 VIX** | 國際投資人有沒有在害怕 |
| 🇹🇼 **台指波動率** | 台股本地震不震 |
| 📐 **大盤位階** | 加權指數現在算貴還是便宜 |
| 💰 **融資水位** | 散戶有沒有在借錢 all-in |
| 🏦 **外資期貨** | 法人偷偷在做多還是做空 |
| 👥 **散戶估算** | 散戶手上多單多還是空單多 |

**怎麼用這個分數**:

| 溫度 | 標籤 | 操作建議 |
|---|---|---|
| ≥ 70 | ☀️ 偏熱(樂觀) | 訊號多但留意過熱回檔 |
| 55~69 | 🌤️ 略偏多 | 正常按訊號進場 |
| 45~54 | 🌥️ 中性 | 觀望盤、訊號模糊 |
| 30~44 | 🌦️ 略偏空 | 警戒、減碼、嚴格停損 |
| < 30 | ❄️ 偏冷(恐慌) | **反向常是長線買點**、分批承接 |

⚠️ **這個溫度不是預測明天漲跌**,而是衡量「市場結構健康度」。
**31 分** 不是說明天會跌,而是說**現在新進場、加碼,風險報酬比不划算**。

## 🏆 選股是怎麼算分的(滿分 10)

每個 **✓ 各得 1 分**,加總滿分 10:

| 面向 | 分數 | 怎麼拿(各 1 分) |
|---|---|---|
| **法人** | 3 | ✓ 投信買超　✓ 外資買超　✓ 投信＋外資**雙買** |
| **籌碼** | 3 | ✓ 券相關(資減券增/軋空)　✓ 大戶持股增加　✓ 散戶減少 |
| **技術** | 2 | ✓ 技術面三合一(均線多頭／量價齊揚突破／連續量增,任一成立)　✓ KD 低檔金叉 |
| **基本** | 1 | ✓ 連續 3 個月月營收年增(YoY)為正 |
| **大盤** | 1 | ✓ 近 20 日報酬贏大盤(相對強度 RS) |

> 「**籌碼共振**」(大戶↑ 且 散戶↓ **同時**成立)只用來**排序優先**,不另外加分(大戶、散戶本來就各自獨立 1 分,同時成立自然累積到 2 分)。

**過關門檻 7 分**,但會動態調整:
- 大盤跌破季線 → 門檻 +1(空頭時從嚴)
- 大盤資料抓不到 → 門檻 -1(RS 訊號失效時補償)

| 資料 | 多久抓一次 | 為什麼 |
|---|---|---|
| 股票清單 | 每天 | 反映新上市/下市 |
| 三大法人買賣超 | 每天 | 補近 15 個工作日 |
| 融資融券 | 每天 | 同上 |
| 日 K 線 | 每天 | 取得當日收盤價 |

| 月營收 | **每月 1~12 日抓** | 公司每月 10 日前公告上月營收 |

**省 API 的設計**:不該抓的時候就不抓。

## 🛠 疑難排解:資料顯示異常時

**症狀**:UI 跳「資料嚴重異常(大量股票缺最新日 / 最新日總量只有均量 ~28%)」,或加權指數停在前一天。

**根因有兩種,先分辨是哪一種**(資料源 yfinance/Yahoo 本來就不是 100% 可靠):

| | A. Yahoo 一次性延遲 | B. yfinance 限速惡化 |
|---|---|---|
| 特徵 | 過幾小時/隔天重抓就補齊;缺的股票每次不太一樣 | 重抓多次都補不齊;log 大量 `Expecting value: line 1 column 1`(空回應=被擋) |
| 性質 | 偶發、會自己好 | 持續、越抓越嚴重 |
| 處理 | **等幾小時 → 按「強制重抓日 K」一次**(或等排程) | 上緩解方案:縮 `chunk_size`、加批次間延遲、`threads=False`、失敗股票補抓一輪 |

**SOP**:
1. 別慌、別狂按重抓(每按一次重抓 ~2000 檔,Yahoo 沒資料時狂按只會讓 IP 被擋更兇)
2. 先**等幾小時或隔天**,再按一次「強制重抓日 K」
3. 補齊 → 是 A(一次性延遲),沒事;**連 1~2 天補不齊** → 是 B(限速),才動手做緩解或換資料源
4. 健康檢查跳警告 = **系統在保護你**(擋住缺料別拿去選股),不是壞掉

> 💡 加權指數自 2026-05-30 起主來源已改為**證交所官方 TAIEX**(yfinance 為備援),不再有「指數延遲一天 / 數值與 Yahoo 奇摩對不上」的問題;個股日 K 仍走 yfinance,故上述 A/B 主要針對個股。

### 2026-05-30(下午)— 數字更誠實 + 期貨/ETF 試算 + 過熱煞車 + 系統自我體檢

- 🚦 **過熱/估值煞車(防追高)** — 股價離均線太遠時亮黃燈:個股頁的「進場節奏」會說明原因,選股清單也能一鍵「排除過熱股」。
- 📌 **個股層級績效** — 新增一張表看「系統選過的哪些股票真的有賺」(入選次數、勝率、平均報酬),找出常勝/常賠標的。
- 🚨 **系統失效警報** — 自動盯著「最近的選股還賺不賺」,明顯轉差時網頁亮紅黃燈、Telegram 主動通知(只在變差時推,不洗版);資料還太少時誠實顯示「累積中」不亂報。
- 🛡️ **更穩** — 風險指標在樣本太少時標「樣本不足」不亂給數字;新增煙霧測試當改動安全網;修掉一個線上回測的崩潰。

> 🔎 **搜尋小升級**:期貨保證金分頁的搜尋框,代號或股名都能查。

### 2026-05-30 — 策略「自我檢驗實驗室」+ 加權指數改官方源

把策略績效頁擴充成「用自己的歷史資料驗證」的實驗室,回答「進場後怎麼操作最好」:

- 🔑 **選股歷史 30 天 → 365 天** — 這是讓下面各種回測「樣本長得大、跨得過一次大盤回檔」的關鍵(向前累積,最多一年)。
- 🔬 **訊號歸因** — 拆解 10 個計分條件,看「哪一條真的帶來報酬」。
- 🧪 **大盤濾網實證** — 比較「全部進場 vs 只在多頭 vs 只在空頭」哪種期望值較好。
- 🚪 **出場規則回測** — 模擬固定持有 / 停損 / 移動停損 / 停利共 6 種,標出最賺(🏆)與最有效率(⚡)的。
- 📈 **加權指數改抓證交所官方** — 根治 yfinance 常延遲一天、盤中值殘留、跟 Yahoo 奇摩對不上的問題(yfinance 留作備援)。

- 🗂 **分頁整併** — 把「入選熱度榜」和「產業輪動」合併成同一個分頁(當時的整理;後續又新增了期貨保證金、資金配置等,目前共 6 個分析分頁,見上方「網頁有哪些分頁」)。

> 共同前提:這些回測都要**累積上百筆、跨過一次大盤回檔**才有可信結論。目前資料還少、又全在多頭,多會顯示「累積中/樣本不足」——工具已備好,時間到自動有答案。

## 🤔 常見問題

### Q1: 為什麼選股結果跟昨天一樣?
**很可能是正常的**。如果你用嚴格訊號(法人連 5 日買 + 籌碼共振),同一檔股票連續 2~3 天上榜很合理 — 法人不會今天買、明天就停。

如果**連續 5 天完全一樣**才該懷疑。常見原因:
- 沒按「開始選股」(只更新資料不會自動重跑)
- 資料其實沒更新成功(看頂部「資料更新」expander 的時戳)

### Q2: 「大盤資料抓取失敗」是什麼意思?
yfinance 偶爾抓不到 ^TWII(尤其雲端 IP 被 Yahoo 限速時)。
**現在已加保險**:會先讀本地 parquet,失敗才打 yfinance。一般不會再看到這訊息。

### Q3: 推送的 Telegram 訊息怎麼變空白了?
可能 AI 模型今天都用完了(OpenRouter 每天 50 次免費)。推播會略過 AI 點評但其他內容正常。

### Q4: 第一次部署到 Streamlit Cloud 開頁面要等很久?
冷啟動本來就慢(雲端容器在 boot)。
**正常情況**:首頁 ~ 3 秒、點 K 線圖 ~ 2 秒。
**異常**:超過 30 秒沒反應 → Manage app → Reboot 強制重啟。

### Q5: GitHub Actions 跑完沒看到 cache 更新?
看 GA log 最後一行有沒有「**將快取存回 GitHub**」這段:
- ✅ 有 → 等 Streamlit Cloud 同步(~ 1 分鐘)
- ❌ 沒有 → workflow 沒設好,要加 `git commit + push` 步驟

### Q6: 「市場溫度走勢」一直顯示「明天起會自動畫成趨勢圖」?
這個圖需要**累積 ≥ 2 天**才會畫。網頁每天有人打開一次就會自動累積一筆。
過 1 週左右就會有完整的趨勢線。

## 🛠 出問題時的自救清單

| 症狀 | 自救步驟 |
|---|---|
| 網頁打不開 | Streamlit Cloud → Manage app → Reboot |
