# 📊 台股全自動選股助理

一個**自己用、24 小時運作**的台股選股工具,每天盤後自動幫你掃過全市場 ~ 1800 檔股票,
挑出符合「**法人在買 + 大戶在吃貨 + 技術面剛起漲 + 營收有成長**」的潛力股,
透過網頁看分析、透過 Telegram 每天收推播。

**最棒的是:全套免費**。雲端主機 / 資料源 / AI 點評都不用付一毛錢。

## 🎯 這套工具能幫你什麼

### 早上開盤前
打開網頁就能看到:
- 📋 **昨晚自動跑出來的達標股清單**(通常 5~20 檔)
- 🌡️ **市場溫度計**(0~100 分)告訴你今天該積極還是觀望
- 📈 **大盤多空狀態**、外資/散戶誰在做多
- 🤖 **AI 操作建議**(150 字短評)

### 平常想研究某檔股票
搜尋框打代號 → 立刻跳出:
- K 線圖(含買賣訊號標記)
- 三大法人/大戶/融資融券走勢
- AI 對這檔的看法
- 倉位計算機(你能虧多少 → 反推該買幾張)

### 每天 17:00 左右
打開 Telegram → **自動推送今日選股**,訊息含:
- 達標個股 Top 15
- 主流產業(看資金往哪流)
- 昨天有今天沒了的股(可能該停損)
- 自選股警示(MA 跌破/KD 死叉/外資連賣)

## 🌡️ 大盤情緒指標(這套工具的特色之一)

把 **6 個訊號** 揉成一個 0~100 的「市場溫度」:

| 指標 | 在說什麼 |
|---|---|
| 🇺🇸 **美股 VIX** | 國際投資人有沒有在害怕 |
| 🇹🇼 **台指波動率** | 台股本地震不震 |
| 📐 **大盤位階** | 加權指數現在算貴還是便宜 |
| 💰 **融資水位** | 散戶有沒有在借錢 all-in |
| 🏦 **外資期貨** | 法人偷偷在做多還是做空 |
| 👥 **散戶估算** | 散戶手上多單多還是空單多 |

**怎麼用這個分數**:

| 溫度 | 標籤 | 操作建議 |
|---|---|---|
| ≥ 70 | ☀️ 偏熱(樂觀) | 訊號多但留意過熱回檔 |
| 55~69 | 🌤️ 略偏多 | 正常按訊號進場 |
| 45~54 | 🌥️ 中性 | 觀望盤、訊號模糊 |
| 30~44 | 🌦️ 略偏空 | 警戒、減碼、嚴格停損 |
| < 30 | ❄️ 偏冷(恐慌) | **反向常是長線買點**、分批承接 |

⚠️ **這個溫度不是預測明天漲跌**,而是衡量「市場結構健康度」。
**31 分** 不是說明天會跌,而是說**現在新進場、加碼,風險報酬比不划算**。

## 🏆 選股是怎麼算分的(滿分 10)

| 拿幾分 | 怎麼拿 |
|---|---|
| **3 分** | 三大法人(外資/投信/自營)買賣超 |
| **3 分** | 大戶持股增加 + 散戶減少(籌碼共振) |
| **2 分** | 技術面:KD 低檔金叉 + 量價齊揚突破 60 日新高 |
| **1 分** | 月營收 YoY > 10% 且月增 > 0 |
| **1 分** | 該股近 20 日報酬贏大盤(相對強度) |

**過關門檻 7 分**,但會動態調整:
- 大盤跌破季線 → 門檻 +1(空頭時從嚴)
- 大盤資料抓不到 → 門檻 -1(分數天花板被砍時補償)

## 🗄 資料怎麼抓、多久更新一次

| 資料 | 多久抓一次 | 為什麼 |
|---|---|---|
| 股票清單 | 每天 | 反映新上市/下市 |
| 三大法人買賣超 | 每天 | 補近 15 個工作日 |
| 融資融券 | 每天 | 同上 |
| 日 K 線 | 每天 | 取得當日收盤價 |
| 大戶持股 | **只在週六/日抓** | TDCC 每週五結算、週末才更新 |
| 月營收 | **每月 1~12 日抓** | 公司每月 10 日前公告上月營收 |
| 加權指數 / VIX | 每天 | 加權指數=證交所官方;VIX=美股恐慌指數 |
| 期貨保證金資料 | **每週**(7 天內略過) | TAIFEX 個股期貨標的+乘數、台指期保證金金額;變動少,週更即可(省 API) |

**省 API 的設計**:不該抓的時候就不抓。
例如月營收已經抓到本月新資料、又是月中 13 號之後 → 自動跳過,不再浪費請求。

## 🛠 疑難排解:資料顯示異常時

**症狀**:UI 跳「資料嚴重異常(大量股票缺最新日 / 最新日總量只有均量 ~28%)」,或加權指數停在前一天。

**根因有兩種,先分辨是哪一種**(資料源 yfinance/Yahoo 本來就不是 100% 可靠):

| | A. Yahoo 一次性延遲 | B. yfinance 限速惡化 |
|---|---|---|
| 特徵 | 過幾小時/隔天重抓就補齊;缺的股票每次不太一樣 | 重抓多次都補不齊;log 大量 `Expecting value: line 1 column 1`(空回應=被擋) |
| 性質 | 偶發、會自己好 | 持續、越抓越嚴重 |
| 處理 | **等幾小時 → 按「強制重抓日 K」一次**(或等排程) | 上緩解方案:縮 `chunk_size`、加批次間延遲、`threads=False`、失敗股票補抓一輪 |

**SOP**:
1. 別慌、別狂按重抓(每按一次重抓 ~2000 檔,Yahoo 沒資料時狂按只會讓 IP 被擋更兇)
2. 先**等幾小時或隔天**,再按一次「強制重抓日 K」
3. 補齊 → 是 A(一次性延遲),沒事;**連 1~2 天補不齊** → 是 B(限速),才動手做緩解或換資料源
4. 健康檢查跳警告 = **系統在保護你**(擋住缺料別拿去選股),不是壞掉

> 💡 加權指數自 2026-05-30 起主來源已改為**證交所官方 TAIEX**(yfinance 為備援),不再有「指數延遲一天 / 數值與 Yahoo 奇摩對不上」的問題;個股日 K 仍走 yfinance,故上述 A/B 主要針對個股。

  - `fetch_taifex_stock_futures`:**個股期貨標的清單(~297 檔)+ 契約乘數** → `stock_futures_*.parquet`

- 分頁有兩種模式:
  - **個股期貨**:輸入代號 → 自動判斷有無期貨、帶最新收盤 → 算契約值/原始/維持保證金/槓桿。保證金**比例可調預設 13.5%**(分級 13.5/16.2/20.25% 會調整,以公告為準);維持以「原始 ×~0.767」估算
  - **台指期(大/小/微台)**:點值固定(200/50/10),契約值用**加權指數**(已改官方源),保證金金額**直接抓 TAIFEX 公告**(可調);自動算槓桿(目前約 15.5 倍)
- 對比「期貨保證金 vs 現股/指數全額」,並提示槓桿放大與追繳風險
- 這兩項資料變動少 → **固定每週六更新**(`_should_skip_weekly`:僅「週六且距上次≥6天」才抓;非週六/太近略過;`--force` 有檔也略過;「從未抓過」即時 bootstrap)。**過期補抓安全網**:檔齡 ≥9 天(代表漏了週六)時任一天都補抓,連 `--force` 也補,避免漏一次週六就 stale 一整週
- ⚠️ 需先跑過一次 `fetch_cache.py` 產生清單/金額,分頁才有資料(否則顯示「尚無快取」優雅降級)

> 📌 **期交所保證金調整機制**(為何週更就夠):TAIFEX 依官方規則「**每日**收盤計算保證金,**變動幅度達調整標準才適時調整**,自公告日**次一交易時段**起生效」。
> 也就是**門檻/波動驅動、不定期、無固定週幾**——日期隨波動散落(大跌大漲/連假前較常調)。
> 故週更足夠;最多慢幾天,在意時(如連假前)手動刪 `cache/idx_margin_*.parquet` 重抓即可。

> 共同前提:這些回測都需要**累積上百筆、跨過一次大盤回檔**才有可信結論;
> 目前資料少且全在多頭,會先顯示「累積中/樣本不足」,工具已備好,時間到自動有答案。

## 🤔 常見問題

### Q1: 為什麼選股結果跟昨天一樣?
**很可能是正常的**。如果你用嚴格訊號(法人連 5 日買 + 籌碼共振),同一檔股票連續 2~3 天上榜很合理 — 法人不會今天買、明天就停。

如果**連續 5 天完全一樣**才該懷疑。常見原因:
- 沒按「開始選股」(只更新資料不會自動重跑)
- 資料其實沒更新成功(看頂部「資料更新」expander 的時戳)

### Q2: 「大盤資料抓取失敗」是什麼意思?
yfinance 偶爾抓不到 ^TWII(尤其雲端 IP 被 Yahoo 限速時)。
**現在已加保險**:會先讀本地 parquet,失敗才打 yfinance。一般不會再看到這訊息。

### Q3: 推送的 Telegram 訊息怎麼變空白了?
可能 AI 模型今天都用完了(OpenRouter 每天 50 次免費)。推播會略過 AI 點評但其他內容正常。

### Q4: 第一次部署到 Streamlit Cloud 開頁面要等很久?
冷啟動本來就慢(雲端容器在 boot)。
**正常情況**:首頁 ~ 3 秒、點 K 線圖 ~ 2 秒。
**異常**:超過 30 秒沒反應 → Manage app → Reboot 強制重啟。

### Q5: GitHub Actions 跑完沒看到 cache 更新?
看 GA log 最後一行有沒有「**將快取存回 GitHub**」這段:
- ✅ 有 → 等 Streamlit Cloud 同步(~ 1 分鐘)
- ❌ 沒有 → workflow 沒設好,要加 `git commit + push` 步驟

### Q6: 「市場溫度走勢」一直顯示「明天起會自動畫成趨勢圖」?
這個圖需要**累積 ≥ 2 天**才會畫。網頁每天有人打開一次就會自動累積一筆。
過 1 週左右就會有完整的趨勢線。

## ⚠️ 重要提醒

1. **這不是投資建議**。所有分數、訊號、AI 點評都只是**資料整理**和**機率參考**。
2. **沒有任何方法可以保證賺錢**。歷史勝率 60% 不代表下一檔會賺。
3. **資料可能延遲或錯誤**。Yahoo Finance 不是即時資料、TWSE 也偶有延遲。
4. **AI 是輔助、不是神諭**。AI 點評偶爾會幻覺、會自相矛盾,當作另一個意見即可。
5. **務必親自驗證每一筆交易**。系統只是減少你找股票的時間,不能取代你的判斷。

## 🛠 出問題時的自救清單

| 症狀 | 自救步驟 |
|---|---|
| 網頁打不開 | Streamlit Cloud → Manage app → Reboot |
| 選股結果是 0 檔 | 檢查門檻是否設太高、或大盤資料異常 |
| K 線圖一直轉圈 | 重新整理頁面(Ctrl+F5),Streamlit Cloud cache 太久 |
| Telegram 沒推播 | 看 GitHub Actions log 看有沒有錯誤 |
| 想重抓今日資料 | UI 點「📥 抓取今日最新資料」或「🔄 強制更新日 K」 |
| 想清除錯誤的 cache | 右上角 ⋮ → Clear cache → 重整 |
